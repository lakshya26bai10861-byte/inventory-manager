# 📦 Inventory Manager

A desktop app to track products, stock levels, sales, and low-stock alerts.

## 📖 Overview
Small shops and warehouses need a simple way to track stock.
This app helps:
- Register and log in as staff
- Add products with price, quantity, and category
- Record sales (which auto-reduce stock)
- Get **low-stock alerts** when items run low
- See analytics: total value, category breakdown, revenue

Built with Python, Tkinter, and SQLite — no external libraries needed.

## ✨ Features
1. **User Management** — register and login
2. **Product & Stock Management** — add, list, delete products with live status
3. **Sales & Analytics** — record sales, view revenue, low-stock alerts, category breakdown

## 🛠 Technologies Used
- **Python 3** — main language
- **Tkinter** — GUI (built-in)
- **SQLite** — database (built-in)
- **Git & GitHub** — version control
