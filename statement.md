# Project Statement — Inventory Manager

## 🎯 Problem Statement
Small businesses often track stock in notebooks or Excel sheets.
This leads to:
- Missed reorder deadlines
- Lost sales when items run out
- No visibility into which products sell best

A lightweight, offline inventory tool solves all three.

## 🧭 Scope
Covered:
- User registration and login
- Product management (add, view, delete)
- Sales recording with auto stock deduction
- Low-stock alerts
- Analytics: stock value, category breakdown, revenue

Not covered (yet):
- Multi-branch warehouses
- Supplier portals
- Barcode integration
- Cloud sync

## 👥 Target Users
- Small shop owners
- Warehouse staff
- Kirana / grocery stores
- Anyone managing physical stock

## ⭐ High-Level Features
1. **User Management** — secure login for staff
2. **Product & Stock Management** — CRUD with live status
3. **Sales & Analytics** — record sales, low-stock alerts, reports
